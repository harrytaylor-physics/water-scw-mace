# docs/

- `deck.html` — self-contained results deck (open in any browser; arrow
  keys / space to navigate, `g` for grid overview). Plain black-on-white
  per group style. Figures load from `figures/`; where a figure is not yet
  copied the slide shows the exact ARC source path in its place.
- `figures/` — copy targets listed per slide inside the deck.
- `METHODS.md` — full methods reference.
